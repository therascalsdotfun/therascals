# Rascals USDC fee vault (testnet)

A fixed 50-basis-point, fee-only NEP-141 receiver with an immutable token/router, per-roll idempotency and recoverable owner withdrawals. See [deployment, transfer evidence and integration limits](../../docs/fee-vault-testnet-2026-11-01.md). This standalone NEAR-testnet contract is not wired to the Solana Devnet roll executor and does not implement a timelock or mainnet USDC integration.
